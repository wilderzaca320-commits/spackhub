## Brand & Style

The design system establishes a high-performance, dark-mode marketplace interface engineered for AI engineers, prompt designers, and creative technologists. It communicates technical precision, rapid asset discovery, and platform reliability while maintaining an engaging visual atmosphere.

The aesthetic fuses **Modern Glassmorphism** with **Technical Minimalism**:
- Deep, obsidian slate backdrops allow multi-model visual outputs and colorful prompt outputs to command primary focus.
- Micro-interactions prioritize immediate clarity: crisp translucent navigation bars, illuminated borders on focus, and calibrated metadata chips.
- Vibrant, model-specific chromatic markers (indigo, cyan, emerald, amber, magenta) provide instant cognitive categorization without overwhelming user focus.

## Colors

The palette relies on deep slate foundations complemented by high-luminance functional accents that visually index different AI model architectures:

### Surface & Neutral Tiers
- **Canvas Base:** `#0B0F19` (Deep Slate Navy) - Foundation background across all standard viewports.
- **Surface Elevation 1 (Cards, panels):** `#131A2B` - Elevated container background.
- **Surface Elevation 2 (Hover states, menus):** `#1E293B` - High-interaction container fill.
- **Subtle Stroke / Dividers:** `#1E293B` - Base structural borders.
- **Active / Accent Stroke:** `#334155` - Default hover state outline.
- **Text Primary:** `#F8FAFC` - Pure contrast for prompt titles, prices, and main body copy.
- **Text Secondary:** `#94A3B8` - Labels, prompt token counts, model tags, and timestamps.
- **Text Muted:** `#64748B` - Inactive controls, placeholder text, and subtle icons.

### Model Accent Matrix
- **Core Action & Platform Accent (Violet-Indigo):** `#6366F1`
- **Midjourney / Image Generation (Cyan):** `#06B6D4`
- **ChatGPT / OpenAI Ecosystem (Emerald):** `#10B981`
- **Claude / Anthropic Reasoning (Terracotta Amber):** `#F59E0B`
- **Flux / Creative Diffusion (Magenta):** `#EC4899`

## Typography

The type scale balances geometric structure with readability:
- **Headlines & Labels (Plus Jakarta Sans):** Provides geometric confidence and punchy character for card headings, tags, model titles, and commercial pricing numerals.
- **Body & Metadata (Inter):** Supplies neutral legibility in dense data layouts, prompt parameter panels, and documentation blocks.
- **Code & Prompt Variables (JetBrains Mono):** Formats variable placeholders (e.g., `[keyword]`, `{aspect_ratio}`) within prompt previews.

## Layout & Spacing

The marketplace utilizes a 12-column responsive fluid grid designed around dynamic card densities:

### Breakpoints & Geometry
- **Desktop (≥ 1280px):** 12-column layout, `margin: 2rem` (max-width bounded to 1440px), `gutter: 1.5rem`. Marketplace prompt grid defaults to 4 columns.
- **Tablet (768px – 1279px):** 8-column layout, `margin: 1.5rem`, `gutter: 1.25rem`. Prompt grid adapts to 2 or 3 columns.
- **Mobile (< 768px):** 4-column layout, `margin: 1rem`, `gutter: 1rem`. Prompt grid reflows to 1 or 2 columns with horizontal scroll-snapping for filter chips and model pills.

### Spatial Rhythm
Component layouts strictly align to 4px and 8px step multiples. Inner card structures enforce `space-sm` between micro-badges, `space-md` for internal panel padding, and `space-xl` for macro-section offsets.

## Elevation & Depth

Visual hierarchy operates on physical light models tuned specifically for dark mode:

1. **Level 0 (Base Canvas):** Solid `#0B0F19`. Zero elevation.
2. **Level 1 (Cards & Data Containers):** Solid `#131A2B` framed by a 1px solid `#1E293B` stroke. Diffuse shadow: `0 4px 20px -2px rgba(0, 0, 0, 0.4)`.
3. **Level 2 (Hover States & Dropdowns):** Subtle gradient stroke transition (`rgba(99, 102, 241, 0.4)` to `rgba(6, 182, 212, 0.2)`). Box shadow: `0 12px 32px -4px rgba(0, 0, 0, 0.6)`. Hovered cards introduce an ultra-subtle directional glow: `0 0 24px -6px rgba(99, 102, 241, 0.25)`.
4. **Level 3 (Modals & Command Palettes):** Backdrop overlay with `background: rgba(11, 15, 25, 0.8)` and a `20px` blur. Modal container uses `#131A2B` with a 1px `#334155` border and deep ambient shadow `0 24px 64px -12px rgba(0, 0, 0, 0.8)`.
5. **Glassmorphism Layer (Global Navigation & Floating Action Bars):** `background: rgba(11, 15, 25, 0.75)`, backdrop filter blur `16px`, saturated to 180%, bottom border `1px solid rgba(255, 255, 255, 0.08)`.

## Shapes

The design system employs a `Rounded` (Level 2) geometry:
- Standard UI cards, input boxes, and dropdown menus utilize `rounded-lg` (16px / 1rem).
- Interactive buttons and filter pills use specialized contours: buttons leverage `8px` (0.5rem), while categorical status badges and model chips use pure pill forms (`9999px`).
- Modal surfaces and spotlight prompt cards use `rounded-xl` (24px / 1.5rem) to soften large surface breaks.

## Components

### Buttons
- **Primary CTA:** Gradient background from `#6366F1` to `#4F46E5`, white text, 8px corner radius. Glow effect on hover: `box-shadow: 0 0 16px rgba(99, 102, 241, 0.4)`.
- **Secondary / Glass Button:** Background `rgba(30, 41, 59, 0.6)`, 1px border `rgba(255, 255, 255, 0.1)`, hover background `rgba(51, 65, 85, 0.8)`.
- **Ghost:** Transparent background, text `#94A3B8`, hover text `#F8FAFC`.

### Model Pill Badges
Compact pill markers (`roundedness: 9999px`) indicating model compatibility:
- **Midjourney:** Background `rgba(6, 182, 212, 0.12)`, text `#06B6D4`, border `1px solid rgba(6, 182, 212, 0.3)`.
- **ChatGPT:** Background `rgba(16, 185, 129, 0.12)`, text `#10B981`, border `1px solid rgba(16, 185, 129, 0.3)`.
- **Claude:** Background `rgba(245, 158, 11, 0.12)`, text `#F59E0B`, border `1px solid rgba(245, 158, 11, 0.3)`.
- **Flux:** Background `rgba(236, 72, 153, 0.12)`, text `#EC4899`, border `1px solid rgba(236, 72, 153, 0.3)`.

### Prompt Cards
- Composed of `#131A2B` elevated surface, 16px radius, and 1px `#1E293B` outer boundary.
- Top section houses a 1:1 or 16:9 media preview with a subtle inner border overlay.
- Metadata row contains the model pill badge on the left and a bold pricing tag (e.g., `$4.99`) using `label-md` on the right.
- On hover, the border dynamically transitions to an illuminated indigo-to-cyan gradient stroke, accompanied by a subtle 2px vertical lift.

### Input Fields & Search Bars
- Background `#0B0F19`, 1px solid border `#1E293B`, 8px border radius, inset padding `12px 16px`.
- Hero search fields incorporate a left-aligned search icon in `#64748B`, an integrated right-aligned keyboard shortcut badge (`⌘K`), and an active focus outline of `1px solid #6366F1` with `box-shadow: 0 0 0 3px rgba(99, 102, 241, 0.2)`.

### Selection Controls (Checkboxes & Radios)
- Base: 18px square (checkbox) or circle (radio), `#131A2B` fill with `#334155` border.
- Selected: `#6366F1` fill, white micro-icon checkmark, outer glow `0 0 8px rgba(99, 102, 241, 0.3)`.

### Code & Prompt Preview Panels
- Monospaced snippet containers (`JetBrains Mono`, 13px) rendered inside `#0B0F19` with partial obscuring (blur-mask) for paywalled marketplace previews.
- Interactive "Copy Prompt" floating button tucked top-right, transitioning to an emerald check confirmation state upon execution.
